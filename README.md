# 買いタスク（買い足す＋タスク）

コンソール上で動作する、日常生活における消耗品のストック残量チェッカーです。自宅にある日用品の在庫状況をシンプルに管理し、買い忘れや二重買いを防ぐことを目的としています。

## 機能一覧 (CRUD)

1. **登録 (Create)**
   - 消耗品の新規登録を行います。（品名、カテゴリ、残量ステータス、メモ）
   - 期限あり商品の登録　食品などの賞味期限（Expiration Date）を伴うアイテムの登録にも対応しています。
2. **参照 (Read)**
   - 全件表示: 登録されているすべてのストックを表示します。
   - 購入品レコメンド: 残量が「残りわずか」「なし」のアイテムのみを自動で絞り込んで表示します。
3. **更新 (Update)**
   - 指定したIDの品名、残量ステータス、メモなどを最新の情報に上書き編集します。
4. **削除 (Delete)**
   - 指定したIDのストック情報を一覧から削除します。

## データ設計

各ストックアイテムは以下のデータを保持します。

| 項目 | 型 | 説明 |
| :--- | :--- | :--- |
| **ID** | `int` | 管理番号（自動割り振り） |
| **品名** | `String` | 消耗品名（シャンプー、食器用洗剤など） |
| **カテゴリ** | `String` | 分類（キッチン、バスルームなど） |
| **残量** | `int` | 在庫状況（十分あり、残りわずか、なし） |
| **メモ** | `String` | 補足情報（例: 詰め替え用、特売日に購入など） |
| **期限** | `String` | 賞味期限・消費期限（食品などの期限ありアイテム用） |

## クラス構成

本システムは、役割を明確に分けた以下の4つのクラスで構成されています。

* **Item (モデル)**
  - 個別商品のデータを保持する入れ物。
  - 残量ステータスを判定して文字列に変換するメソッド（`getStatusLabel`等）を持ちます。
* **ItemService (ビジネスロジック)**
  - リスト（`ArrayList`）の管理と、裏側でのCRUD処理（追加・参照・更新・削除）を担当します。
* **Menu (UI制御)**
  - コンソール画面へのメニュー表示と、`Scanner` を用いたユーザーからのキーボード入力・エラー対策を制御します。
* **Main (エントリーポイント)**
  - アプリの起動スイッチ。`Menu` クラスを呼び出してメインループを開始します。
* **FoodItem (子モデル)**
  - `Item` クラスを継承した食品・期限付きアイテム用のクラス。
  - 賞味期限フィールドを持ち、`getItemInfo()` をオーバーライドして情報を拡張しています。

## 実行方法

1. `Main.java` をコンパイルおよび実行してください。
2. コンソール上にメインメニューが表示されます。案内に従って半角数字を入力し、各機能を操作してください。
